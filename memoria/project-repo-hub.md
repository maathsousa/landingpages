# project-repo-hub

> Pasta landingpages versionada em github.com/maathsousa/landingpages; plano futuro de um hub que lista e linka todas as LPs


Em 12/11/2026 a pasta landingpages/ virou repositório git (branch main) e foi enviada para https://github.com/maathsousa/landingpages. Um .gitignore deixa de fora .playwright-mcp/, graphify-out/, .impeccable/review/ e os PNGs de teste.

O usuário quer, no futuro (não agora), criar um hub na raiz que mostre todas as landing pages criadas, com links para cada uma. Ver [[project-netz-cafe]] e [[project-netz-laranja]].

**Why:** centralizar e apresentar as LPs por cultura.
**How to apply:** novas LPs entram como pasta própria (netz-<cultura>/) na raiz, prontas para o hub listar; commitar/pushar só quando o usuário pedir.
